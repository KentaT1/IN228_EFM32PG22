# IN228_EFM32PG22

A firmware project for the Silicon Labs **EFM32PG22** microcontroller to interface with the **TI INA228** high-precision digital power monitor over I2C.

## Purpose
This project provides a driver and application logic to monitor bus voltage, load current, and die temperature. It includes support for sensor calibration, configurable ADC averaging, and hardware alert management.

## High-Level Architecture
- **Application Layer (`app.c`, `main.c`)**: Manages the system lifecycle, initialization, and the periodic polling loop.
- **Driver Layer (`ina228.c`, `ina228.h`)**: Implements the TI INA228 communication protocol, including register-level access, current calibration, and alert threshold configuration.
- **Hardware Abstraction (Gecko SDK)**: Utilizes `sl_i2cspm` (I2C Simple Polled Master) for robust I2C communication and `sl_iostream` for VCOM (UART) data reporting.
- **Configuration (`config/`)**: Contains hardware-specific pin mappings and peripheral configurations generated by Simplicity Studio.

## Key Features
- **Measurements**: Real-time monitoring of VBUS (Bus Voltage), Current, and Internal Die Temperature.
- **Calibration**: Dynamic calculation of `SHUNT_CAL` based on shunt resistance and maximum expected current.
- **Alerts**: Support for Bus Over/Under Voltage, Shunt Over/Under Voltage (Current), and Over-Temperature interrupts.
- **Diagnostics**: Detailed reporting of the INA228 `DIAG_ALRT` status register via VCOM.
- **Configurable Sampling**: Adjustable ADC conversion times and averaging (1 to 1024 samples) to balance noise and speed.

## Hardware Requirements
- EFM32PG22 Microcontroller (e.g., PG22 Dev Kit).
- TI INA228 Power Monitor.
- I2C Pull-up resistors (if not present on the sensor breakout).
- VCOM connection for serial output.

- **Thermal Drift Stability**: Monitor `VSHUNT` at 0mA while varying chip temperature to verify the $\pm 0.01 \mu V/^\circ C$ offset drift specification.
- **High-Voltage Linearity & CMRR**: Apply bus voltages from 12V up to 85V (if safe/available) to verify `VBUS` measurement linearity and ensure the `CURRENT` reading remains stable across the full common-mode range.
